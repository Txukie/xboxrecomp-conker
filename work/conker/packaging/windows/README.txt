Conker: Live & Reloaded - static recompilation, Windows build
https://github.com/Txukie/xboxrecomp-conker

Run conker_recomp.exe. The first time it asks for your copy of the game
(USA release): a disc image (.iso, or the .7z/.zip holding it) or the
default.xbe of an extracted disc. An image is installed once, which takes a
minute or two.

Needs Windows 10 or later (64-bit) and a GPU with a Vulkan 1.3 driver.
Under Linux it runs with Proton or Wine: add conker_recomp.exe to Steam as a
non-Steam game and pick Proton under Compatibility.

Settings, saves, mods and the installed game live in
%LOCALAPPDATA%\ConkerRecomp. The log of the last run is conker.log there.

SDL2.dll is SDL 2 (zlib license, README-SDL.txt). The game's data is not
included.

Ejecuta conker_recomp.exe. La primera vez pide tu copia del juego (versión
USA): una imagen de disco (.iso, o el .7z/.zip que la contiene) o el
default.xbe de un disco extraído. Una imagen se instala una vez, en uno o
dos minutos.

Necesita Windows 10 o posterior (64 bits) y una GPU con driver Vulkan 1.3.
En Linux funciona con Proton o Wine: añade conker_recomp.exe a Steam como
juego que no es de Steam y elige Proton en Compatibilidad.

Ajustes, partidas, mods y el juego instalado están en
%LOCALAPPDATA%\ConkerRecomp. El registro de la última ejecución es
conker.log, ahí mismo.
